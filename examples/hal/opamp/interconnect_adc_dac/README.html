Example: hal_opamp_interconnect_adc_dac

Example version: 2.0.0

How to use the OPAMP with internal connections to other analog peripherals DAC and ADC.

1. Detailed scenario

This example connects three peripherals: an OPAMP, a DAC, and an ADC (referred to below as the OPAMP, the DAC, and the ADC).

The DAC output is internally connected to the OPAMP non-inverting input, while the OPAMP output and the ADC input share the same GPIO pin, so no external jumper is required.

Initialization phase: At the beginning of the main() function, the mx_system_init() function is called to initialize the peripherals, the Flash interface, the system clock, and the SysTick.

The application executes the following example steps:

Step 1: Configures the DAC to continuously generate a signal on the OPAMP non-inverting input.

Step 2: Configures the OPAMP in follower mode, with its non-inverting input internally connected to the DAC and its output connected to the ADC input through a shared GPIO pin.

Step 3: Configures the ADC to acquire the OPAMP output.

Step 4: Starts the DAC, the OPAMP, and the ADC. The DAC updates its output and the ADC samples the resulting OPAMP output, using a software-triggered conversion in polling mode.

End of example: The example status is reported via the variable ExecStatus, and the status LED remains turned on in case of success.

You can verify that the example runs properly via the status LED and the ExecStatus, DacRawData and AdcRawData variables.

If you enable USE_TRACE, you can follow these execution steps in the terminal logs:

2.1. Block Diagram

2.2. IPs configuration

OPAMP: configured in follower mode (unity gain).

  • Non-inverting input: connected internally to the DAC output.
  • Output: connected to the ADC input through a shared GPIO pin.

DAC: outputs a fixed mid-scale voltage (VDDA/2) on the OPAMP non-inverting input, with no trigger needed.

ADC: acquires the OPAMP output with a single, software-triggered conversion in polling mode.

3. Hardware environment and setup

3.1. Generic Setup

There is no external jumper needed to run this example. The DAC output is internally connected to the OPAMP input, while the OPAMP output and ADC input share the same GPIO pin.

4. Troubleshooting

Find below the points of attention for this specific example.

Calibration: This example uses factory trimming values for the OPAMP. However, calibration can be performed to adjust the values to your working environment.

Peripheral routing: Not all STM32 series/lines offer the same routing options between the OPAMP, DAC and ADC. Refer to the datasheet and reference manual of your device before adapting this example to another board.

Voltage Range: The OPAMP delivers a voltage between 0V and VDDA (not always 3.3V). Be careful when using 1.8V boards.
