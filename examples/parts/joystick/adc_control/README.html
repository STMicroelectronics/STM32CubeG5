Example: joystick_adc_control

Example version: 2.0.0

This example demonstrates how to use the joystick part driver to read the key state using the ADC interface in polling mode.

1. Detailed scenario

Initialization phase: At main program start, the mx_system_init() function is called. It initializes the peripherals, nonvolatile memory (such as flash memory, NVM, or external memories), MPU regions (if applicable), the system clock, and the SysTick.

Step 1: Initializes the Joystick instance.

Step 2: Read the state of the Joystick key. The status LED is toggled when any key is pressed.

End of example: The example runs indefinitely in a loop if no errors occur (step 2 is executed in loop).

If you enable USE_TRACE, you can follow these execution steps in the terminal logs:

[INFO] Step 1: Device initialization COMPLETED.

[INFO] Step 1: Press any key on the joystick.

[INFO] Step 2: Key Pressed - CENTER

2. Example configuration

JOYSTICK: Joystick ADC Part Driver

  • The joystick part driver is controlled by an ADC interface. It configures the key min/max values according to the ADC configuration and the hardware setup (resistance values).

ADC: The ADC is configured with these specific parameters

  • Single channel conversion.
  • Software trigger.
  • 12 bits resolution.
